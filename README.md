# Market-Hub

A modern e-commerce frontend where users can browse, search, and buy products — or list their own for sale.

🔗 **Live Demo:** [https://feranmi247.github.io/Market-Hub/](https://feranmi247.github.io/Market-Hub/)

## Features

- 🛍️ Browse products by category
- 🔍 Live search + filtering
- 💰 Sort by price and name
- 📄 Load More pagination
- ❤️ Wishlist (favourites)
- 🛒 Cart with quantity controls
- ✅ Multi-step checkout with validation
- ➕ Sell your own products
- 💾 Persistent state via localStorage
- 📱 Fully responsive

## Tech Stack

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript (no frameworks)
- GitHub Pages for hosting

## Run Locally

Just open `index.html` in your browser — no build step needed.
